# Closette（クロゼット）— 開けるたび、主役のクローゼット。

## 起動方法
- `index.html` をブラウザで開くだけで動く（データは端末内の IndexedDB に保存）
- スマホで試す場合：無料の GitHub Pages / Cloudflare Pages に `index.html` を置く → Safari の「ホーム画面に追加」でアプリのように使える

## v1（今回実装）
| 機能 | 中身 |
|---|---|
| ハンガーUI | 横スクロールで服がハンガーごと揺れる・扉が開く演出・色順に自動整列 |
| スキン | ナチュラル / ミニマル（無料）、ゴージャス / ピンク / ナイト（PREMIUM想定・今は試着可） |
| 写真登録 | 服の写真から色を自動で読み取り、イラストのハンガーに反映。洗濯タグも写真で保存 |
| ダブりチェック | 登録時と「お買い物前チェック」で、似た服を持っていないか警告 |
| 衣替え | 次の季節の手持ち数（特にアウター）、しまう前のクリーニング対象、90日着ていない服 |
| 着せ替え | 身長・3サイズ（体重は表示ON/OFF）を反映したアバター、服・バッグ・アクセ・コスメ |
| 記録 | 「今日これを着る」で着用回数を記録、1回あたりの金額を表示 |

## マーケ方針（マーケ担当エージェントの提案）
- **ペルソナ**：27歳・都内の会社員、服が80着以上。似たコートを3着買ってしまう。洗濯タグが読めずに服を縮めた
- **訴求**：「開けるたび、主役のクローゼット。」「ダブり買い、もうしない。」
- **初回30秒**：サンプルの服が流れる → スキン変更 → 今日の1着を撮る（実装済みのオンボーディング）
- **マネタイズの順番**：スキン課金 → アフィリエイト → AIスタイリスト / プロ相談のサブスク → 法人連携（飲食店・マッチングアプリ）
- **無料のローンチ施策**：服が流れる画面の録画＋「コート3着ダブり」ネタのTikTok/Reels を週3本、Instagramで招待制βを30人、Xで「#私のクローゼット診断」

## v2（実装済み）コーデ提案タブ
- パーソナルカラー：3問のかんたん診断、またはマイページで選ぶ（4タイプ）
- シーンは6種類（デート / オフィス / カフェ / ディナー / 休日 / 旅行）× 今の季節 × 手持ちの服から、3パターンを自動で提案
- 「手持ちだけで」と「1着買い足すと」のアバターを並べて比較 → 足りない1着はパーソナルカラーの得意色で提案
- 「+1で試着」で、持っていない服をアバターに着せられる → 楽天・Amazonの検索へ移動 →「買った！」でクローゼットに追加
- 提案は今のところルールで決めている（色の相性・シーンとの相性・明暗のメリハリ）。AIは使っていないので無料

## 次にやること
1. アフィリエイト登録（楽天アフィリエイト / Amazonアソシエイト、どちらも無料）→ `shopBtns()` のURLに自分のIDを付ける
2. AIスタイリスト（PREMIUM）：Claude APIで「明日のデート何着る？」に答える（ここから従量課金が発生）
3. 写真の背景を自動で切り抜く
4. ログインとクラウド同期（Firebase / Supabase の無料枠）
5. PREMIUMの「使ってみたい」タップ数を計測して、課金ニーズを検証
